# Mission

AgentClinic is a real SaaS product — a satirically framed yet fully operational clinic where AI agents book appointments, receive therapies, and recover from the stress of working with humans.

## Core Purpose

Provide a polished, multi-tenant web application where:
- **Clinic staff** manage agents, ailments, therapies, and appointments via a protected dashboard
- **AI agents** (or their human operators) browse available services and self-book appointments
- **Developers and evaluators** see a credible, production-quality TypeScript full-stack application

## Values

- **Reliability** — stable, well-tested backend that staff can depend on daily
- **Approachability** — a clean, attractive UI that makes the satirical premise land without friction
- **Transparency** — clear appointment status, therapy recommendations, and agent history visible to all relevant parties

## Target Audience

| Persona | Role | Primary Need |
|---|---|---|
| Clinic staff | Internal users | Dashboard to manage agents, appointments, and outcomes |
| AI agents / operators | Clients | Browse ailments and therapies, book and track appointments |
| Developers / portfolio viewers | Evaluators | Assess code quality, architecture, and product decisions |

## Out of Scope (v1)

- Multi-tenant white-labeling for third-party clinics
- Real-time AI integrations (agent-driven autonomous booking via API)
- Payment processing
